# 05_quality_assessment

Quality assessment of the 123 synthesised studies on the five items of Dybå and Dingsøyr: QA1 clear objective, QA2 experimental setup described, QA3 comparison against a baseline, QA4 limitations discussed, QA5 conclusions supported by the evidence. Each item was scored 0, 0.5 or 1.0 from the full text of the paper.

`pdf_qa_scores.csv` holds the per-paper scores. Mean total 4.12, minimum 2.5, maximum 5.0. Distribution: 24 x 5.0, 40 x 4.5, 23 x 4.0, 17 x 3.5, 16 x 3.0, 3 x 2.5. No paper fell below the 2.0 sensitivity threshold.
