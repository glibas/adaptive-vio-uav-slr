# 06_data_extraction

`extractions_full.csv` holds the 20-field extraction for each of the 86 included studies: identification (id, citation, year, venue, DOI, country/institution, class), architecture (VIO type, fusion method), front-end (visual modality, feature representation, IMU preintegration), adaptation (online/adaptive component), platform, evaluation (datasets, metrics, addressed conditions), and analysis (key contribution, stated limitations, relevant research questions, reviewer notes).
