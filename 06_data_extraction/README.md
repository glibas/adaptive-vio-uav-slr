# 06_data_extraction

`extractions_full.csv` holds the 20-field extraction for each of the 182 included studies, together with the coded columns behind the synthesis tables: auxiliary sensors and their fusion weight, height channel, front-end representation, per-keypoint quality scoring, and limitation codes. The columns are described in Section 10 of the protocol (`00_protocol/`).

The `*_evidence` columns give the passage of the study that supports the coded value, with the page where it was recorded.
