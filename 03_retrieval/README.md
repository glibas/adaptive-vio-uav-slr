# 03_retrieval

Full-text retrieval of the 232 sought reports. `retrieval_status.csv` lists each report with `pdf_retrieved` (Y, or `N (EXC-8)` when no channel yielded the full text) and `in_final_corpus`.

124 reports were retrieved; 108 could not be obtained through any channel and were excluded under EXC-8. The PDFs themselves are not redistributed in this repository.
